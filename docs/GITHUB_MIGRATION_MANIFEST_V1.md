Do not delete automatically. Review separately:
- repositories with placeholder names
- one-off tutorials
- dated bootstrap repos
- imported forks no longer used
- duplicate prototypes

Deletion requires a separate explicit review because repository deletion is irreversible and is not part of this migration.
